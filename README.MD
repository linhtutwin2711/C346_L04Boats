# GetABoat

GetABoat is a mobile app built with React Native (Expo) that shows a list of boats for sale.
Each boat is displayed as a card with an icon, the boat name, a short description and a picture.
This app was made to practise creating a reusable user-defined component and passing data into it with properties (props).

# Features
- Shows 6 boats in a scrollable list
- Each boat has its own icon and icon colour
- Boat names are displayed in capital letters
- Uses one reusable `Boats` component instead of repeating the same code 6 times
